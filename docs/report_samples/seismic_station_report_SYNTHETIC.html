5. Method

Records are read from miniSEED or SAC by content; the station response, when its StationXML is given, is built from the file's stages as evalresp builds it and removed in the frequency domain with a water level and a pre-filter. Spectra are Welch estimates (Hann window, half overlap); persistent lines are bins above a running-median floor in a fraction of the windows. Detectability compares band power in each listed source's exclusive windows with the quiet baseline. An array's direction is frequency-domain beamforming over a slowness grid with the array response function's half-power width as its resolution.
