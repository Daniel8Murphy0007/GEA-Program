1. Intended use

Flag every sample GOOD / RANGE / ROC / FLATLINE / SPIKE / STALE / GAP with the rule and limit that fired, per tag, before any evaluation.

2. Out-of-scope uses

Not an alarm; not a correction - flagged samples are excluded from evaluations and counted, never repaired.

7. Known limitations

(1) Rules are per-sample; a slow drift is not a quality flag (it is the drift evaluation's job). (2) The spike rule at daily cadence can flag real operational excursions; each flag prints its deviation so an engineer can judge.
