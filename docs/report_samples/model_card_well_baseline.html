1. Intended use

Expected pressure and temperature at a gauge station (by measured depth) for drift evaluation: residual = measured - baseline. With a measured profile the baseline interpolates the archived log; without one it uses linear gradients from surface conditions.

2. Out-of-scope uses

Not a reservoir model; not a flow model; not for allocation; not a prediction of production behaviour. A linear-gradient baseline is a template and must be replaced by the well's measured profile before any classification is acted on.

7. Known limitations

(1) Linear gradients are a template, not a measurement. (2) Deviation is applied only when a survey is supplied. (3) The baseline has no production dynamics; drawdown reads as an unexplained trend by design and is routed to investigation.
