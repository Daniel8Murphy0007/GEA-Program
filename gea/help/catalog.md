# The catalogue

> The program ships 52 public datasets, each with a provenance sidecar saying where it came from, under what licence, and what it covers. A sidecar does not say what in this program reads the entry; the register does. `gea catalog --list` prints every entry with the bands, commands and reports that take it, or the plain statement that nothing does yet - CARRIED, NO BAND - and the gate holds that register to the code. The entries with a use since this page was written: every LAS log runs through the strata survey; seven measured-friction and strength datasets become the envelope a slip statement discloses its coefficient against; the Volve core checks the published sandstone range.

**The command**: `gea catalog --list` (the register), `--unused` (the carried entries, with the reason), `--check` (every entry read through its own reader, the shape or the error), `--entry <name> --info` (the provenance in full and how it reads), `--entry <name> --stream-csv out.csv` (the entry as a stream file any other command ingests), `--friction` (the measured friction and strength, each with its source, and the envelope against Byerlee's 0.6), `--core` (the Volve 15/9-19 A core plugs against the published sandstone range). `gea survey --catalog <entry>` runs the strata survey on any LAS entry - Scorpio E1 (South Australia), University 6-17 (Texas), Kennetcook #2 (Nova Scotia), Collingwood 1-28 (Kansas), L07-01 (Dutch North Sea), 15/9-19 SR (Volve) - and says what it found or why it did not estimate.

**What it writes**: the register - entry, kind, tier, file size, USED or CARRIED, and each use in the user's terms; the check - 52 of 52 entries read; the friction envelope - friction coefficients 0.21 to 0.90 on 70 measurements from three datasets (ODP Costa Rica, IODP Hikurangi, IODP Nankai), cohesion 188-990 kPa (Sumatra), vane shear 19.5-290 kPa (Barbados), fault-zone peak shear strength 1.7-1.9 MPa at slow slip (JFAST), uniaxial compressive strength 3-265 MPa on crystalline cores (KTB pilot hole) - none from the Permian, and the page says so; the core check - bulk density per plug as grain density x (1 - porosity) + brine x porosity, the brine stated, 65 of 70 Volve plugs inside the published 2.05-2.55 g/cc sandstone range, written into the rock inventory model card's evaluation.

**The number to check**: `--check` must read every entry; `--list` must show no entry registered as used that no module names (the gate checks both ways); the core check's count against the model card's evaluation line.

**What this page will not call a measurement**: a friction coefficient for the site - the envelope is what was measured on other rocks elsewhere, with each source named; it bounds how far a law can sit from a measurement, it does not give the fault's own. A use an entry does not have - a carried entry is said to be carried, and whether to drop it from the wheel is the owner's call, not this page's. A survey estimate from too little support - a log excerpt with fewer than five usable stations is NOT ESTIMATED with the reason, as the real excerpts above show. A core bulk density the core did not report - it is derived from grain density and porosity with the brine density stated, and labelled as derived.
