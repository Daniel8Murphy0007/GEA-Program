# The interval against the mapped tops

> The second geological statement this program makes about a well, and the first question a reviewer of a disposal well in a seismic response area asks: where does the injection interval sit against the mapped geology? The operator declares the interval and the elevation it is measured from; the formation-top layers the site brought give a bracket at the well; the program puts the two side by side and says ABOVE, BELOW, or NOT RESOLVED - and whether the declared depth tier agrees with the mapped base of the formation the plan names.

**The command**: `gea workspace --path C:\site --action set-well --well SWD-1 --top-interval-ft 9850 --base-interval-ft 10400 --depth-ref TVD --ref-elev-ft 2962 --ref-elev-datum KB --ref-elev-source "completion report W-2"` declares the interval in true vertical depth below the kelly bushing at the elevation the completion report states. `--elev-3dep` instead fetches the GROUND elevation at the declared surface position from the USGS 3D Elevation Program point service (`gea elevation --lat --lon` does the same for any position) and stores it as the reference with datum GL and the service's raster as the source. Layers are told what they map: `--action add-layer --name "EIA Wolfcamp top" --layer Wolfcamp_Elevation_Isopachs.zip --member Wolfcamp_Formation_Elevation_201712 --formation-name Wolfcamp --role top`, and the isopach the same way with `--role isopach`. Then `--action interval --well SWD-1` writes the statement; the well page's "Interval against the mapped tops" card and the SRA packet's section 2c carry it, and section 2d sets the catalogue's events against the mapped faults.

**What it writes**: the declared interval converted to subsea elevation - reference elevation minus depth, so 9,850 ft below a KB at 2,962 ft is -6,888 ft subsea - and, for each contours layer with a bracket at the well, whether the interval is ABOVE the mapped top (its base shallower than the shallowest the top can be), BELOW it (its top deeper than the deepest the top can be), or NOT RESOLVED (the bracket overlaps the interval). For a formation with a top layer and an isopach layer, the base bracket by the arithmetic shown - top minus thickness, both as brackets - and the declared depth tier against it: CONSISTENT, INCONSISTENT, or NOT RESOLVED. For the catalogue events inside the SRA, the nearest mapped fault trace to each epicentre with its distance and bearing, and the counts within 1, 2 and 5 km. Written to `reports/wells/<id>/interval.json` and audited as `well.interval`.

**The number to check**: the subsea top and base of the interval, and the status beside each top - and the tier line: `CONSISTENT`, `INCONSISTENT`, or `NOT RESOLVED` against the mapped base. `NOT DECLARED` names what is missing.

**What this page will not call a measurement**: a depth between two contours - a bracket is two contours, never a value between them, and an interval the bracket overlaps is NOT RESOLVED, not placed. A kelly-bushing depth from a ground elevation - 3DEP answers the ground; the KB is higher by a height only the completion report states, and the page says so whenever the reference is GL. A measured depth - this program converts true vertical depth only; a deviated well's MD needs its survey first. The tier being right - the statement is whether the declaration and the map agree; the completion report is the record. An event's cause - an epicentre near a mapped trace at the map's scale is a distance, not an attribution, and the hypocentral depth is not used.
