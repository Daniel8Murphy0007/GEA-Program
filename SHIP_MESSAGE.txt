v0.65.0 — THE WINDOWS INSTALLER

GEA-Program now installs like any Windows program.

- GEA-Program-Setup-0.65.0.exe on the release: installs for you alone,
  with no administrator rights; asks where the site workspace is (an
  existing one such as C:\site is used as it is) and never changes or
  deletes it; adds Start-menu and desktop shortcuts, an Add/Remove
  Programs entry and, if you want it, a start at sign-in. A newer setup
  installs over the older one in place.
- The GEA-Program shortcut starts the control panel when it is not
  running and opens it in a window of its own (Microsoft Edge's app
  window; Chrome's, else a browser tab, where Edge is missing).
- The program's icon in the notification area says whether the control
  panel is running and opens, starts or stops it.
- Signed with the publisher's certificate once one is configured;
  installed, upgraded with the panel running, and uninstalled on the
  build machine before it is attached to the release.
- Fixed: stop-dashboard.cmd found nothing to stop on Windows 11 24H2 (no
  wmic there); the logon task stopped the dashboard after three days.
