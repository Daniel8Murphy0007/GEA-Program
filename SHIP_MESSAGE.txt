v0.55.0 — HTTPS

The control panel can now be opened from the site network over HTTPS,
without a proxy in front.

Give the workspace the site's own certificate - from the company's
certificate authority, which managed computers already trust - or let
the program make a self-signed one. The certificate is made with the
standard library alone: an RSA key and an X.509 server certificate for
every name and address the panel is reached by. TLS 1.2 is the floor.
The session cookie is marked Secure, every answer tells the browser to
stay on HTTPS, and a plain http:// request on the same port is sent to
HTTPS. A certificate in its last 30 days raises an alert. A workspace
whose certificate files are broken does not start, rather than falling
back to plain text.

Administration has a new HTTPS card: how it stands, what this run
serves, the certificate to download for the site's computers (never the
key), and the change. `gea tls` does the same from a terminal, and
`gea help https` explains it. The Stop, Restart and auto-restart
controls on the Administration page did nothing before this release;
they work now.

Section CX is new, four checks. The gate is 463 checks. The standalone
guard is clean.
