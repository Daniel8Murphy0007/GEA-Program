v0.89.0 — ASSISTANT ACCESS (MCP)

`gea mcp`: the site readable by an assistant over the Model Context
Protocol. Twenty-three tools, each one of the program's own pages - the
rig time, the roadmap, the drilling alerts, the fluid balance and the
rest - returning what the program itself prints. Local (no port: the
child process's standard streams), read-only (every file hashed before
and after in the gate), logged, and the tools offered chosen by the site,
because what a tool returns goes to whoever runs the model. Both eras of
the protocol: revision 2026-07-28 and the handshake of 2025-11-25 and
earlier. The Assistant access tab, with one button for Claude Desktop;
`gea mcp`, `gea help mcp`. Section EH; gate 581.

Install from inside the program: Audit/Update, "Fetch the kits", "Install now".
