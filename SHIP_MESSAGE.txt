v0.109.0 — ALERT RULES: A CARD FOR EACH RULE THAT RAISES AN ALERT

Added: the Alert rules tab, under Watch & report. A card for each of
the twelve rules that raise an alert from a drilling record: what it is
for, how it decides in the words of the module that applies it, when
its alert is raised, the channels it cannot do without, its thresholds
as they stand with the source of any change, the wells it can read, how
often it has been raised, and what it will not call a measurement.

Added: each rule's own checks, run again on request and carried by the
report.

Added: the other alerts listed with their tabs, so every alert the
service can raise is on one page.

Added: gea alert-rules, gea help alert-rules.

These are rules with thresholds set by hand, not models fitted to data.
None has been set against confirmed field events, so no card gives a
hit rate. No rule is changed by this release.

Gate 641.
