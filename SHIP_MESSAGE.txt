v0.57.0 — THE IT REVIEW

The answers an operator's IT department asks for before installing GEA
now ship with it.

`gea security` prints the security overview from any installation: where
the site's data lives, every host the program can reach and when (there
is no telemetry), the one port it listens on, HTTPS, company sign-in and
the roles, the audit log, the bill of materials, and how to check a kit.
The acceptance gate checks the overview against the code, so it cannot
drift from what the program does. SECURITY.md says how to report a
vulnerability.

Every kit is now attested by the build that made it, so a site can check
a downloaded kit with `gh attestation verify`. The Windows kit carries a
file catalog of every file in it. The build signs that catalog as soon
as a code-signing certificate - Azure Artifact Signing or a PFX - is
configured. Until then it ships unsigned and the build says so.

Fixed: `gea guide`, `gea help` and the other front-door commands now work
from the kit's own launcher.

Section CZ is new, three checks. The gate is 470 checks. The standalone
guard is clean.
