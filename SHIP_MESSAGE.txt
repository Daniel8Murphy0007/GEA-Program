v0.72.0 — THE MONITOR ON THE BOX

A screen on the recorder for the person on the pad.

- Plug any HDMI monitor into the Pi and run kiosk.sh once: from then on
  the screen shows RECORDING in green, or what is wrong in red, the GPS
  clock, the rig's bit depth, the disk, and every channel's last minute
  with the ground sensors' spectrogram. Nothing to press.
- The same view is on the box's page at /live from any browser on the
  pad network.

GEA-Recorder-0.72.0.tar.gz on the release carries it. GEA-Program itself
is unchanged in use; install GEA-Program-Setup-0.72.0.exe over the old
one to keep the versions together. C:\site is kept as it is.
