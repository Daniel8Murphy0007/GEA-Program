v0.29.1 — THE KIT'S GATE: TWO CHECKS THAT ASSUMED A CHECKOUT

v0.29.0 reached PyPI and both ci runs were green; both kit builds failed at
the step that installs the kit offline and runs its gate. Two of the new
checks assumed they were running in a checkout: BW3 ran
tools/catalog_positions.py and BX2 read README.md from beside the package,
and an installed kit carries neither. The program was never wrong; its gate
was, inside the kit.

Each check now does what the tester-guide and report-sample checks have
done since v0.4.0: in a checkout it reads the file; in a kit it says so and
checks what the kit does carry. The fix was proven the way the kit runs -
both sections executed from a copy of the package alone - before this ship,
and that run is now part of the prechecks for every leg that adds a check.

Nothing else changes. The gate is 373 checks. The standalone guard is clean.
