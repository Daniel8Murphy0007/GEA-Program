v0.66.0 — THE SITE'S OWN NAME

Every install kit named a new workspace "Pad 3". It no longer does.

- A workspace the kit's launchers make is named after its folder.
- The setup asks the site's name when it makes a new workspace and makes
  it with that name; a workspace that already exists (C:\site) keeps its
  own name, untouched. Silent installs: /SITENAME="...".
- An administrator can rename the site in the control panel:
  Administration -> Site settings -> Site name (also in the first-run
  guide). The new name heads every report written from then on, and the
  change is in the audit log.
- The build workflows use the Node 24 versions of GitHub's actions.
