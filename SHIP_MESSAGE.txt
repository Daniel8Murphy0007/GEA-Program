v0.17.1 — ONE KIT RUN PER SHIP

The kit workflow raced itself. Every ship pushes main and the tag together
and the workflow ran on both: two runs building the same commit and
attaching the same kits to the same release within seconds of each other.
Three ships went red at the attach step with the kits already on the
release - v0.13.0, v0.16.0, v0.17.0 - and each was patched where it hit.
The cause was two writers. The workflow now runs once per ship, on the
tag, and by hand; a concurrency group on the commit queues a manual run
behind a tag run instead of beside it. One writer per release. The attach
script keeps its tolerances as a second line.

No program code changes. The gate is 340 checks. The standalone guard is
clean.
